# Photography and social assets

- `hero.avif` / `hero.webp`: full-bleed 16:10 or wider hero (recommended 2400 px wide)
- `experience-wine.avif` / `.webp`: portrait wine-pouring detail
- `experience-people.avif` / `.webp`: candid, atmospheric gathering detail
- `founder.avif` / `.webp`: editorial founder portrait
- `og-image.jpg`: 1200 × 630 social sharing image

The first release intentionally uses locally rendered abstract night imagery and
does not invent event photography. Add `<picture>` sources at the marked media
slots in `index.html` when commissioned photographs are available.
